# Code of conduct

Morph follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep feedback about the work. Harassment of any kind isn't welcome.

To report a problem, contact the maintainers privately through a [GitHub security advisory](https://github.com/VenusOne-Lee/morph/security/advisories/new) (it reaches maintainers only) and say it's a conduct report. We'll respond within two working days.
